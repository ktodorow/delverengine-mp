## Shared contract

Host runs original native acceptance, targeting, collision, damage/healing, status combination and timers, AI, resource mutation, secondary spawning, destruction, and world time. Clients receive bounded current state for recoverable behavior and ordered events for live-only cues, then call presentation-safe native paths. Replica presentation cannot invoke damage, healing, spread, spawning, loot, charge use, or AI callbacks.

Every peer builds the Active Floor from its own owned content, so identical construction is a precondition for every row below. Host announces one Shared Floor seed with `SessionReady`; `SharedFloorBuild` seeds each generator the native `Level.loadFromEditor` path draws from (`Game.rand`, libgdx `MathUtils.random`, item/monster/entity manager generators), derives separate streams per build phase, marker, prefab group and initialized entity, and pins spawn-affecting graphics options to desktop defaults (detail 3, quality 1.0) only while building. Lighting and rendering keep each peer's own settings. Each client reports a bounded `SharedFloorFingerprint` (per-category counts and digests of class, stable id, position, texture and monster type; items excluded because Host physical item state replaces them); Host removes a client whose floor differs, with the differing categories, before worlds can diverge. Single-player never seeds.

Source, target, effect, dynamic entity, physical item, session, and floor generation identities remain stable. New snapshots recover current phase and remaining time; transient starts, pulses, frame sounds/lights, impacts, and fizzes are not replayed after reconnect. Owner-only camera, HUD, inventory, potion knowledge, dialogue, and map state remain private.
